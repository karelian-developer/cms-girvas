**Шаблон «GIRVAS: Lite»** представляет собой **первичный шаблон** для системы управления содержимым «ГИРВАС». Обычно уже идет вместе с поставкой программного обеспечения и предустановлен.

Дизайн выполнен в **минимальной стилистике**, адаптирован под цветовую контрастную и черно-белую палитру, очень комфортно смотрится на всех устройствах. Не является широкоформатным (имеет максимальную ширину).

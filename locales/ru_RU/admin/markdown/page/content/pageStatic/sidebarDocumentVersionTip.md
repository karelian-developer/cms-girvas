Эта страница — **юридический документ**. Каждая новая редакция сохраняется в истории: с версией, локализацией и датой.

**Зачем.** По 152-ФЗ согласие фиксируется на **конкретную редакцию**, которую видел пользователь. История версий это доказывает.

**Как выпустить.** Укажите номер версии (например, `1.1`) → нажмите **«Выпустить версию»** → подтвердите.

**Важно.** Публикация необратима. Если правите опечатку — просто сохраните, версию не выпускайте.

Выборки записей представляют собой набор записей определенных категорий, которые внедряются напрямую в шаблон сайта путем добавления в нужное место шаблонной переменной типа **{ENTRIES_SAMPLE:<SAMPLE_NAME>}**.

Обратите внимание, что сама шаблонная переменная генерируется автоматически после указания для нее имени и идентифицируется системой во время сборки шаблона.

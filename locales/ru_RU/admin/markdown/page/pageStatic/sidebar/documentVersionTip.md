Укажите версию документа в формате **X.Y** (например, `1.0`, `1.1`, `2.0`).

При сохранении будет создана **новая версия** документа. Предыдущие версии сохраняются в истории и доступны по адресу:

`/page/<имя-страницы>?version=<версия>`

Пользователи, дающие согласие (при регистрации или отправке форм), будут соглашаться **именно с этой версией**.

> **Важно:** для юридических документов **нельзя** менять версию без изменений в тексте. Если текст не изменился — новая версия не создаётся.

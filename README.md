# Система управления содержимым «ГИРВАС»
**Система управления содержимым «ГИРВАС»** — мультиязычная, многопрофильная, бесплатная **CMS** с открытым исходным кодом от компании «Карельский разработчик». Система нацелена на создание оптимизированных веб-ресурсов с высокой скоростью загрузки, поддерживает публикацию контента на разных языках с последующей индексацией поисковыми системами и соответствует принципам цифрового суверенитета.

Разработка ведётся с 2021 года индивидуальным предпринимателем **Шестаковым Андреем Руслановичем**. Система написана на языке **PHP** (версия 8.2 и выше) без использования сторонних фреймворков, базируется на собственном движке.

## ⚙️ Ключевые возможности
* **Создание и управление записями** и статическими страницами, включая поддержку версионирования юридических документов с неизменяемой историей.
* **Организация структуры контента:** категории и дочерние категории с рекурсивным обходом, архив записей с навигацией по датам, полнотекстовый поиск по контенту с учётом локализации.
* **Многоуровневый доступ:** регистрация пользователей, группы, настройка прав доступа.
* **Комментирование:** обсуждение контента с модерацией и управлением.
* **Гибкий внешний вид:** темы оформления, контент-блоки с настройкой отображения по регулярным выражениям.
* **Аналитика и отчётность:** раздел «Отчёты CMS» (Общая сводка, Контент, Безопасность), логирование всех событий, интеграция с Яндекс.Метрикой.
* **Соответствие 152-ФЗ на уровне ядра:** версионирование юридических документов, фиксация согласий с привязкой к версии и локали, отзыв согласий, экспорт данных субъекта, обезличивание ПДн, ротация логов, cookie-баннер для всех посетителей.
* **Мультиязычность:** контент, настройки сайта и юридические документы на разных языках.
* **Встроенный OAuth-провайдер:** сайты на CMS могут выступать сервером авторизации для сторонних приложений.
* **Поддержка двух СУБД:** MySQL и PostgreSQL через единый слой абстракции.
* **Управление формами:** сбор данных через динамические формы с фиксацией согласий.
* **Встроенный SEO-анализатор** контента (работает на стороне клиента).
* **Поддержка Markdown** (встроенный парсер NadvoParse).

## 🛠️ Технические требования
* **Операционная система:** Windows или Linux.
* **Минимальная версия PHP:** 8.2.
* **СУБД:** PostgreSQL 13.13 (и старше), MySQL 5.7 (и старше).
* **Минимальное место на диске:** 50 МБ.

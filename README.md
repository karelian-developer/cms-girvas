# Система управления содержимым «ГИРВАС»
__Система управления содержимым «ГИРВАС»__ - мультиязычная многопрофильная бесплатная __система управления содержимым__ с открытым исходным кодом от предприятия "Карельский разработчик", нацеленная на создание оптимизированного веб-ресурса в плане скорости загрузки его содержимого, создание веб-ресурса любого направления с возможностью публикации контента на разных языках с возможностью последующей индексацией со стороны поисковых систем. Система начала разрабатываться в 2021 году __индивидуальным предпринимателем Шестаковым Андреем Руслановичем__. Система управления разработана на языке программирования общего назначения PHP без использования сторонних фреймворков. Базируется на собственном движке и соответствует принципам цифрового суверинитета.

__14 июня 2024 года__ CMS прошла государственную регистрацию в Роспатенте через Федеральный институт промышленной собственности. В этот же было выдано Свидетельство о государственной регистрации.

__3 октября 2025 года__ CMS «ГИРВАС» [стала применяться](https://xn----7sbbafuqffehcie7cvgcl5a9h7d.xn--p1ai/entry/karelian-developer-center-my-buisness-site-developer) при разработке сайтов субъектам малого и среднего предпринимательства при сотрудничестве с [Центром «Мой Бизнес» Республики Карелия](https://mb10.ru/).

*Система внесена в __Реестр российского программного обеспечения__ __от 27.11.2024 ([запись №25012](https://reestr.digital.gov.ru/reestr/2840045/?sphrase_id=6005236))__ на основании протокола заседания экспертного совета Министерства цифрового развития Российской Федерации __от 14.11.2024 №820пр__.*
